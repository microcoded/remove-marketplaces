# Remove Marketplaces
Automatically hides _“marketplace”_ items on various Australian retailer websites.

## Installation Instructions
- Install Tampermonkey for your browser (or another userscript manager).
- Click [here](https://github.com/microcoded/remove-marketplaces/raw/main/remove-marketplaces.user.js) and press install.

### Limitations
This userscript redirects pages to append URL parameters that hide marketplace items. It may not work properly on websites that use SPA routing without doing a full page reload, and parameters will need to be updated if a retailer change their website structure.
